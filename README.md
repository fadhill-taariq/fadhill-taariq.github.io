# Taariq Fadhil — Portfolio

Source for my personal portfolio site: software projects, my dissertation and a short bio.

**Live:** [taariqf.netlify.app](https://taariqf.netlify.app) · [fadhill-taariq.github.io](https://fadhill-taariq.github.io)

## Structure

```
index.html              # Homepage: bio, selected projects, skills
projects/               # One page per project
assets/styles.css       # Site stylesheet
Dissertation_Report.pdf # Full dissertation report
```

Plain HTML and CSS with no build step. Open `index.html` locally, or deploy the repo root as-is (Netlify: no build command, publish directory `/`).
