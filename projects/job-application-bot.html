Job Application Bot

A local job-application assistant that never needs an AI API key. Paste a job description, point it at your CV, and the local language model will draft a tailored CV, write a cover letter, export both to PDF, and log the application. I wanted something that ran on my laptop, kept everything local, and still gave me a meaningful head start on each application.

Try it live ↗ View on GitHub ↗

The live version runs in demo mode in your browser, with no install and no model. Run it locally with Ollama for real tailoring.

The build

The bot pairs a small interface for pasting a job description with a pipeline that hands the text to a locally-running Ollama model. It produces a CV re-ordered around the role, drafts a cover letter that mirrors the tone of the listing, exports both to clean PDFs, and writes a row into a personal tracker so I can see which roles I've applied to and when.

It has since grown into a fuller pipeline. A job scraper pulls live listings from Google for Jobs and has the local model score each one against my profile. A fact check flags any number or technology in the generated text that isn't in my real CV, so a model "improvement" never reaches an application. My profile can be imported straight from a PDF or Word CV.
