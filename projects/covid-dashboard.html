Covid-19 Personalised Dashboard

A configurable dashboard that pulled together regional pandemic numbers into a single, calm, personal view — I wanted a tiny, opinionated dashboard that pulled just the numbers I cared about, in roughly the order I cared about them, with as little decoration as possible.

The build

A scheduled script pulls case, hospitalisation, and vaccination figures from public data sources, normalises the response shapes, and writes a simple rendered view. The dashboard is configurable — point it at a different region and it adjusts the comparison set automatically.

What I learned

Scripting
Automating the boring parts

Using scripts to fetch, refresh, and reshape data on a schedule.

APIs & data
Pulling from public sources

Working with messy, real-world data feeds and handling their inevitable inconsistencies.

Modelling
Normalising shapes

Wrangling several incompatible APIs into one consistent internal data model.

Dashboards
Information hierarchy

Choosing what's a headline number, what's context, and what's a footnote.

Configuration
User-tunable defaults

Designing the dashboard so a single setting could change the comparison region.

Resilience
Failing gracefully

Handling missing data and broken feeds without blanking the entire view.

Visual design
Calm dashboards

Resisting the urge to add charts and colour until the underlying numbers were trustworthy.

Civic-tech mindset
Building for yourself first

Starting with the tool I wanted to use every morning, rather than a generic dashboard for nobody in particular.

What I'd do next

  • Generalise the framework so it can show any time-series of regional health or environmental data.
  • Replace the rendered view with a small static site that updates from cached snapshots.
  • Add a "what changed today" summary written by a local language model.
