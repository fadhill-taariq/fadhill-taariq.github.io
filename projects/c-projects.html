What's inside

A growing collection of small programs: each one is a deliberate practice piece focused on a specific concept — class design, pointer semantics, the STL, file I/O, simple algorithms, and the basics of building and linking real programs from the command line.

What I learned

Language
C++ fundamentals

Types, references, pointers, headers, and the bones of how a C++ program is put together.

Memory
Ownership & lifetime

Thinking carefully about when things are created, copied, moved, and destroyed.

OOP
Class design

Constructors, destructors, encapsulation, and inheritance — using them sparingly, on purpose.

STL
Standard library

Vectors, maps, iterators, and algorithms as the everyday vocabulary of modern C++.

Tooling
Compile & link

Working at the command line with the compiler — understanding what the build is actually doing.

Debugging
Reading errors patiently

Decoding compiler diagnostics and runtime crashes instead of guessing at fixes.

Algorithms
Small problems, well-solved

Sorting, searching, parsing — the classic exercises that build intuition.

Mindset
Slowing down

Learning that low-level code rewards thinking about a problem before typing.

What I'd do next

  • A small data-structures library implemented from scratch (lists, trees, hash maps) to compare against the STL.
  • One non-trivial project — perhaps a simple interpreter — to tie the exercises together.
  • Introduce CMake and a testing framework to mirror real-world C++ workflows.
